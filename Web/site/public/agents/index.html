AI agents

lil · Claude, Claude Code, ChatGPT and other agents

AI agents can no longer connect to lil health. lil health and lil messages are discontinued. The service shut down on November 25, 2026, and every account's synced data was deleted from my servers that day, with each agent's connection and the log of what agents read.

The servers agents connected to, https://mcp.lil.tech and https://mcp.lil.tech/health, no longer exist. An agent that still has one of them reads nothing: its requests fail. Nothing can be connected again.

Remove lil from your agent

The connector does nothing now, so you can remove it:

  • Claude (claude.ai, or the Claude app): open Customize › Connectors (Settings › Connectors in some versions) and remove the connector you added.
  • Claude Code: claude mcp remove with the name you gave it, such as claude mcp remove lil or claude mcp remove lil-health.
  • ChatGPT: open Plugins and remove the custom MCP server you added.
  • Other agents: remove the remote MCP server with lil's URL.

Agents on your Mac

lil health for Mac could also let agents read the copy of your Health data on your Mac, through a local MCP server (lil mcp or lil health mcp). That copy is still on your Mac, and it's no longer updated. If you connected an agent that way, remove the server from it the same way, for example claude mcp remove lil.

To remove the lil command, delete it from where you installed it: /usr/local/bin/lil, or .local/bin/lil in your home folder. The Privacy Policy says how to remove lil health's copy of your data from your Mac.

What agents already read

An agent sent what it read to its provider's servers (for example Anthropic's or OpenAI's). Shutting lil health down didn't delete that: the provider handles it under its own terms and privacy policy, so ask the provider.
