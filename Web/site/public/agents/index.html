Connect an AI agent

lil health · Claude, Claude Code, ChatGPT and other agents

Connect an AI agent to your lil health account, then ask it about your Health data: how you slept this week, how your resting heart rate has changed this year, or what workouts you did last month. The agent reads your data from lil health's servers, so it works wherever the agent runs, without your Mac.

You need a lil health account with your Health data in it: set up lil health on your iPhone first. When the agent asks you to sign in, use the same Apple ID or Google account.

The URL

Add this URL to your agent as a remote MCP server (some agents call it a connector):

https://mcp.lil.tech/health

The agent then opens lil health's page in your browser. Sign in with Apple or Google, check which agent is asking, and click Allow.

Claude

On claude.ai, or in the Claude app on your Mac or PC:

  1. Open Customize › Connectors (Settings › Connectors in some versions).
  2. Click Add, then Add custom connector.
  3. Name it lil health, paste the URL above, and add it.
  4. Click Connect, then sign in to lil health and allow Claude.

On a Team or Enterprise plan, an owner adds the connector in Organization settings › Connectors first. Then you find it in Customize › Connectors and click Connect.

Claude Code

In a terminal:

claude mcp add --transport http lil-health https://mcp.lil.tech/health

Then, in Claude Code, run /mcp, choose lil-health, and authenticate. Your browser opens lil health's page.

ChatGPT

ChatGPT can add a custom MCP server on some plans and workspaces, sometimes only in developer mode, and its menus change often. Today, on chatgpt.com:

  1. Open Plugins, click the plus button, then Add custom MCP server.
  2. Name it lil health, paste the URL above as the Server URL, and choose OAuth.
  3. Create it, sign in to lil health and allow ChatGPT, then install the plugin.
  4. In a chat, type @ and choose lil health.

If your ChatGPT looks different, see OpenAI's guide to adding a custom MCP server.

Other agents

Any agent that supports remote MCP servers over Streamable HTTP, with OAuth sign-in, can connect: give it the URL above. lil health registers it when it connects, so there's no client ID or secret to enter.

What an agent can read

  • All of your lil health data, read-only. There's no way to share only some kinds of data, and an agent can't change or delete anything.
  • Summaries first: today's numbers, totals and averages over a day, week, month, six months or a year, workouts, sleep, medications and your health details. It reads individual records only when it asks for them, a page at a time.
  • Days in UTC unless the agent asks for your time zone, since lil health's servers don't know where you are. Tell your agent where you are if its days look off.
  • Agents send what they read to their provider, such as Anthropic or OpenAI, under the provider's own privacy policy.

lil health logs every time an agent reads your data: what it asked for and when, never the answers. You can see the log in lil health on your Mac and iPhone. It's kept for 90 days. The privacy policy has the details.

Stop an agent

  • On your Mac: in lil health, open Settings › Agents. Click Revoke… next to an agent, or Turn Off Agent Access… to disconnect them all.
  • On your iPhone: in lil health, open Settings › Connected Agents. Swipe left on an agent to revoke it, or tap Turn Off Agent Access.

The agent is cut off at its next request. You can also remove it in the agent itself: in Claude, Customize › Connectors; in Claude Code, claude mcp remove lil-health. Connecting again asks you to sign in and allow it again.

Agents on your Mac only

lil health for Mac also has a command, lil health, with a local MCP server that reads the copy of your data on your Mac instead (install it with lil health › Install Command Line Tool…). It's off until you turn on “Allow command-line and agent access” in Settings › Agents, which also shows how to connect an agent to it.

Connect an agent to lil mcp: one local server for every lil app, with lil health's tools among them. In Claude Code: 

claude mcp add --scope user lil -- lil mcp

For an agent that should only see lil health, use lil health mcp instead: claude mcp add --scope user lil-health -- lil health mcp.

Other agents take a local (stdio) server: the command is lil's full path, with the arguments mcp, or health mcp for lil health only. Use the full path in Claude Code too if it can't find lil, as when it's started from an app rather than a terminal. Settings › Agents shows the commands with it, ready to copy.

If something doesn't work

  • “No lil health account uses this Apple ID” (or Google account): sign in with the account you use in lil health on your iPhone. Accounts can't be created on the web.
  • The agent finds no data: open lil health on your iPhone and check that it has uploaded your Health data.

Anything else: hello@851.sh.
